## 核心功能

Skills Hub 不仅是一个技能市场浏览器，还是 DeepSeek Harness 客户端与私有化 SkillHub 协同平台之间的核心枢纽：

### 1. 🌐 多源技能市场聚合与动态发现
- **三源技能统一浏览**：一键聚合 **ClawHub**、**SkillHub** 公共生态与企业 **自建 SkillHub Server（Self-hosted）**。
- **实时全局搜索**：支持跨市场搜索全部技能，同名技能按作者与来源隔离区分。
- **智能动态分类**：根据当前技能生态实时动态推导分类标签，告别虚假分类，支持单源或全部来源的精准过滤。
- **本地持久化缓存**：已浏览的技能列表、详情与文件预览自动落盘本地缓存，离线或弱网环境依然顺畅秒开。

### 2. 🛡️ 安装前全景预览与安全洞察
- **完整内容预览**：免安装即可查看技能简介、作者信息、SKILL.md 完整提示词与附带脚本代码。
- **行为与安全风险分析**：基于规则与安全扫描，提前告知技能安装后将调用的工具命令、读取的环境变量（如 API Key）与外部网络请求，保障运行安全。

### 3. 📦 本地技能与工作区统一管理
- **集中清单视图**：在「已安装技能」中一站式管理市场下载技能及用户全局自定义技能。
- **清晰归属溯源**：明确标示每个技能的本地物理路径、安装来源与权限，卸载前提供位置确认，支持安全干净移除。
- **一键上传发布至私有市场**：支持将本地调试成熟的技能**一键打包发布到自建 SkillHub Server**，自定义分类与可见性，进入团队共享与审核流。

### 4. 👤 WorkBuddy 风格账户与服务配置
- **集成式账户体验**：左下角常驻账户与连接状态栏，支持快速登录、注销自建服务账号。
- **平滑自建服务切换**：支持配置或动态切换私有自建服务后端地址，连接健康状态实时感知。

### 5. ⚡ 被动式零开销探活（Passive Probe Architecture）
- **客户端零后台常驻发包**：严格遵循被动架构设计，客户端**不运行任何定时心跳轮询**，不浪费本地算力与带宽。
- **轻量实例登记**：启动或登录时单次向服务端登记客户端环境（设备标识、平台版本与本地接口端点）。
- **管理端主动探活与会话拉取**：由 SkillHub Server 管理后台在需要时主动发起健康探测，支持无感知增量同步。

### 6. 📊 企业管理端集中审计与在线监控（协同 SkillHub Server）
- **在线状态实时大盘**：管理后台概览页提供当前在线用户数（呼吸指示灯）、在线客户端/设备数、接入总数与已同步会话总数。
- **在线人员与设备列表**：清晰查询具体哪些用户账号与计算机当前在线、运行环境及最后活跃时间。
- **会话轨迹集中审计**：管理端一键拉取客户端已发生的对话会话（会话标题、所属工作区、问答轮次、Token 消耗量与更新时间），方便统一质量审计与用量分析。

## 快速开始

适用于 **DeepSeek Harness 0.2.0-rc.2 及以上版本**。[兼容版本清单](./docs/COMPATIBILITY.md)

### 安装插件

打开 **DeepSeek Harness 桌面端 → 插件 → 添加插件**，粘贴以下任意一种安装源：

**GitHub 仓库地址（推荐）**

```text
https://github.com/NanmiCoder/dsh-skills-hub
```

**或 npm 包名**

```text
@nanmicoder/dsh-skills-hub@0.0.3
```

点击 **安装 → 立即启用**，完成后在侧边栏即可看到 **技能市场** 入口。

## 私有服务与管理端联动

如果您部署了私有化 [SkillHub Server](https://github.com/NanmiCoder/skillhubserver)，可实现团队内部技能共享与集中管控：

1. **连接自建服务**：在插件左下角账户菜单中设置您的私有服务器地址（如 `http://your-server:3000`），并输入账号密码登录；
2. **分享技能给团队**：进入「已安装技能」，点击任意本地技能右侧的「上传至自建市场」，填写分类与介绍后即可上架；
3. **管理后台实时监控**：
   - 打开 SkillHub Server 管理后台（默认 `http://your-server:5173/admin/overview`），查看当前在线用户数与客户端清单；
   - 在「会话审计」页面点击 **「刷新并从客户端拉取会话」**，即可集中查阅各客户端的会话元数据、提问轮次与 Token 统计。

## 使用指南

1. **发现与搜索**：按动态分类标签浏览，或直接在搜索框中键入关键词，支持回车或即时筛选；
2. **详情与安全审核**：点击卡片进入详情，确认其所需的工具调用、环境参数与脚本源码；
3. **一键安装**：点击安装后即刻生效，无需重启 Harness，相关技能立即进入当前 Profile 的可调用上下文；
4. **管理与卸载**：进入「已安装技能」，点击「卸载」并二次确认即可干净删除。若卸载 Skills Hub 插件本身，已安装的具体技能仍将完整保留在您的本地目录中。
